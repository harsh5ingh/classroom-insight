## Manual browser capture procedure

### 1. Launch or reuse the real application

From PowerShell in `D:\Coding\SkillWallet\Multimodal`:

```powershell
.\.venv\Scripts\python.exe -m backend.app
```

In a separate terminal, if the existing Vite listener is no longer running:

```powershell
npm run dev
```

Use `http://127.0.0.1:5173/` when Vite is responsive. If port 5173 remains occupied by the existing instance, use `http://127.0.0.1:5000/`; Flask serves the existing production build. Run `npm run build` first only if application source has changed since the last build. Do not kill unrelated processes, reset SQLite or load duplicate demo data.

### 2. Set a consistent viewport

In Chrome/Edge/Brave, open a dedicated tab for the local site. Set page zoom to 100%. Open DevTools, toggle the device toolbar, select Responsive, and set 1440 × 1000 with DPR 1. Use the device toolbar's screenshot command to save the **page viewport**, which excludes DevTools and browser chrome. For full-page views, use the DevTools command menu's **Capture full size screenshot** command. DevTools itself must never appear in the saved image.

Alternatively, use a supported browser automation screenshot method with the same viewport. Do not generate screenshots from HTML mocks, SVG recreations, JSON fixtures or canvas drawings of the interface.

Wait for text to settle into the local Manrope/DM Serif fonts, charts to finish rendering and loading notices to disappear. Hover the pointer over a neutral area to avoid tooltips unless a tooltip is deliberately being documented. Dismiss browser password-save or other unrelated popups. Do not accept credential-saving prompts.

For Employee Login, use an unmodified rectangular browser capture covering the modal heading through Sign in, with nearby blurred background; omit the demo-help area that prints the password. This changes only capture framing, not the site. Note the tighter framing in the caption. If that cannot be framed cleanly, leave this image uncaptured until a safe region capture is available.
